## 📋 نظرة عامة

**لقمة جدتي** هو موقع إلكتروني متكامل لمشروع طبخ منزلي يمني تراثي. يوفر الموقع واجهة رقمية أنيقة لعرض المنتجات، استقبال الطلبات، وإدارة العمليات بشكل كامل من خلال لوحة تحكم احترافية.

المشروع مصمم بـ **أساسيات PHP** فقط، مما يجعله مثالياً للتعلم والتطوير!

---

## ✨ الميزات

### 🌐 للعملاء:
- ✅ تصفح المنتجات مع نظام تصنيفات ديناميكي
- ✅ سلة تسوق متقدمة باستخدام localStorage
- ✅ نظام طلبات سهل وسريع

### 🔐 لوحة التحكم:
- ✅ نظام تسجيل دخول آمن (Sessions)
- ✅ إدارة كاملة للمنتجات (CRUD)
- ✅ رفع وتعديل صور المنتجات
- ✅ إدارة الطلبات وتحديث حالاتها
- ✅ لوحة إحصائيات ديناميكية

## 🗄️ قاعدة البيانات

المشروع يستخدم **4 جداول**:

| الجدول | الوصف |
|--------|-------|
| `products` | المنتجات (اسم، سعر، صورة، تصنيف) |
| `orders` | الطلبات (عميل، هاتف، ملاحظات، حالة) |
| `order_items` | تفاصيل الطلبات |
| `admin` | بيانات المسؤول |

## 🚀 التثبيت

### المتطلبات:
- XAMPP (PHP 7.4+ و MySQL 5.7+)
- متصفح حديث

### خطوات التثبيت:

1. **استنساخ المشروع:**
```bash
git clone https://github.com/Mo-ra778/loqmat-jadati.git
cd loqmat-jadati
```

2. **نقل الملفات إلى XAMPP:**
```bash
# انسخ المشروع إلى
C:\xampp\htdocs\loqmat-jadati\
```

3. **تشغيل XAMPP:**
   - شغّل **Apache**
   - شغّل **MySQL**

4. **إنشاء قاعدة البيانات:**
   - افتح `http://localhost/phpmyadmin`
   - اضغط **Import**
   - اختر ملف `database.sql`
   - اضغط **Go**

5. **تعديل إعدادات الاتصال** (إن لزم):
   - افتح `config.php`
   - عدّل بيانات الاتصال حسب إعداداتك

6. **افتح الموقع:**
```
http://localhost/loqmat-jadati/
```
